# Your Beauty Voyage Guide

**My First University Programming Project**

## About the Project
Your Beauty Voyage Guide is a beginner-level website developed as my first practical programming project at university.

The website provides beauty-related information and guidance through different sections, helping users explore skincare, haircare, and body wellness topics.

## Features
- **Skincare:** Beauty tips and skincare information.
- **Haircare:** Haircare guidance and frequently asked questions.
- **Body & Health:** Content related to body care and wellness.
- **FAQ:** Frequently asked questions.
- **User Pages:** Login and sign-up pages.

## Technologies Used
- HTML
- CSS
- JavaScript
- PHP
- MySQL

## Development Environment
The project was developed and tested locally using XAMPP and MySQL.

## Project Structure
- `app.html` – Main homepage.
- `appskin.html` – Skincare section.
- `apphair.html` – Haircare section.
- `appbody.html` – Body and health section.
- `faq.html` and related FAQ files – Frequently asked questions.
- `login.html` / `login.php` – Login functionality.
- `signup.html` / `signup.php` – Sign-up functionality.
- CSS files – Website styling.
- JavaScript files – Interactive behavior.

## Notes
This project represents my first practical experience in web development during university. It was created as a learning project and reflects my early experience with front-end and back-end web technologies.

The original MySQL database is not included in this repository, so the database-dependent sign-up functionality may require database recreation before it can be used.
